# FastAPI Test API

A small FastAPI project for testing a Python API service with PostgreSQL note queries.

## Features

- Health check endpoint
- API version endpoint
- PostgreSQL note lookup endpoint
- Pydantic validation for item data
- Interactive API documentation generated by FastAPI

## Tech Stack

- Python
- FastAPI
- Pydantic
- PostgreSQL
- Psycopg
- Uvicorn

- Python 3.10 or newer

## Installation

Create and activate a virtual environment:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

Install the project dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Create the local environment file from the safe example and update the connection string with your PostgreSQL password:

```powershell
Copy-Item .env.example .env
```

The `.env` file is ignored by Git. Keep real passwords and other secrets in `.env`, and commit only `.env.example` with placeholder values.

## Run Locally

Start the development server from the project root:

```powershell
uvicorn app.main:app --reload --host 0.0.0.0 --port 8888
```

The API is available at:

- http://127.0.0.1:8888
- Swagger UI: http://127.0.0.1:8888/docs
- ReDoc: http://127.0.0.1:8888/redoc

## API Endpoints

### `GET /health`

Returns the service health status.

```json
{
  "status": "ok"
}
```

### `GET /version`

Returns the current API version.

```json
{
  "version": "0.1.0"
}
```

### `POST /items`

Accepts an item and returns the validated request data.

Request body:

```json
{
  "name": "Notebook",
  "price": 12.5
}
```

Response body:

```json
{
  "name": "Notebook",
  "price": 12.5
}
```

### `GET /note/{id}`

Returns one note from PostgreSQL by its ID. A missing note returns `404 Not Found`.

Example request:

```text
GET /note/1
```

Example response:

```json
{
  "id": 1,
  "title": "First note",
  "content": "This is the first note.",
  "created_at": "2026-09-12T20:12:02.302474+08:00"
}
```

## Database Status

The notes endpoint reads from PostgreSQL using the `DATABASE_URL` environment variable. The `notes` table can be created and seeded with:

```powershell
psql -U dev_user -d fastapi_dev -f .\psql\createtables.sql
```

The database connection, SQL repository, API router, and response schema are separated into their own modules under `app/`.

## Google Sign-In

The API supports Google OpenID Connect sign-in at `/api/auth/google/login`.
Configure `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, and the exact
`GOOGLE_REDIRECT_URI` registered in Google Cloud Console. Set different random
values of at least 32 characters for `JWT_SECRET_KEY` and `SESSION_SECRET_KEY`.
Use `AUTH_COOKIE_SECURE=true` when serving over HTTPS; only local HTTP
development should use `false`.

The callback stores verified Google profiles in `public.member`, issues an
HS256 JWT in an HttpOnly cookie, and redirects to `AUTH_SUCCESS_REDIRECT_URL`.
`GET /api/auth/me` returns the current profile, and `POST /api/auth/logout`
clears the authentication cookie.
The `/api/note` endpoints require a valid JWT in that cookie or a Bearer
authorization header.

Authentication uses `public.users.id` as the JWT subject and links Google
profiles through `public.member.user_id`. The `users.id` column mirrors the
existing `users.uid` so existing foreign keys remain valid. For a database
created with the earlier user/member schema, apply the migration before
starting the updated API. The JWT issuer has been versioned so sessions issued
with the previous `member.id` subject must sign in again:

```powershell
psql "$env:DATABASE_URL" -f .\psql\migrations\20261025_users_member_identity.sql
```
